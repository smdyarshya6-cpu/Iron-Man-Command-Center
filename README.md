# Iron Man Command Center PWA

اپ مدیریت کارها و روتین‌ها با تقویم شمسی، دستیار متنی، یادآوری و تم شخصیت‌ها.

## آپلود روی GitHub / Netlify
1. زیپ را باز کن.
2. **همه‌ی فایل‌ها و پوشه‌ی `icons`** را در ریشه‌ی ریپو (کنار `index.html` قبلی) جایگزین کن و Commit بزن.
3. Netlify خودش دیپلوی می‌کند. اگر نسخه‌ی قدیمی را دیدی، یک بار صفحه را Hard Refresh کن
   (کاربران اپ نصب‌شده خودکار آپدیت می‌شوند چون سرویس‌ورکر حالا network-first است).

## تم شخصیت‌ها
تنظیمات ← ظاهر برنامه ← تم شخصیت‌ها: آیرون‌من، اسپایدرمن، ثور، هالک، کاپیتان آمریکا، پلنگ سیاه، اسکارلت ویچ.
فقط پالت رنگی است (بدون لوگو یا تصویر رسمی). هر تم با حالت روشن/تاریک هم ترکیب می‌شود.
برای افزودن تم جدید، یک خط به انتهای بخش `Character themes` در `styles.css` اضافه کن
(`--h` رنگ زمینه، `--ah` رنگ تأکیدی، `--gh` رنگ دکمه‌ها) و یک مورد به آرایه‌ی `CHARACTERS` در `app.js`.

## هنوز پیاده‌سازی نشده
- همگام‌سازی ابری: ورود با Firebase هست ولی کارها فقط در `localStorage` همین دستگاه ذخیره می‌شوند.
- یادآوری وقتی برنامه بسته است: نیاز به سرور زمان‌بندی دارد (FCM فقط پیام ارسالی از سرور را دریافت می‌کند).
- فونت Vazirmatn و Firebase از سرورهای گوگل لود می‌شوند؛ اگر در شبکه‌ی کاربر مسدود باشند، فونت Tahoma و ورود/ثبت‌نام کار نمی‌کند ولی بقیه‌ی برنامه عادی است.
